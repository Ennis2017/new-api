1. 项目简介

New API 是一个开源的、统一的 AI 模型网关与资产管理系统（"A unified AI model hub for aggregation & distribution"），常被用作 AI API 中转站。它基于知名项目 One API 二次开发，兼容 One API 的数据库结构。

项目地址：https://github.com/QuantumNous/new-api

💡 典型应用场景 个人或企业聚合 OpenAI、Claude、Gemini 等多家厂商 API，用统一 OpenAI 兼容协议对外分发，方便计费、限流、权限管理。

5. 部署方式

方式一：Docker Compose（推荐）

git clone https://github.com/QuantumNous/new-api.git
cd new-api
docker-compose up -d

方式二：Docker 命令 - SQLite 版（最简单）

docker run --name new-api -d --restart always \
  -p 3000:3000 \
  -e TZ=Asia/Shanghai \
  -v ./data:/data \
  calciumion/new-api:latest

方式三：Docker 命令 - MySQL 版（生产推荐）

docker run --name new-api -d --restart always \
  -p 3000:3000 \
  -e SQL_DSN="root:123456@tcp(localhost:3306)/oneapi" \
  -e REDIS_CONN_STRING="redis://localhost:6379" \
  -e SESSION_SECRET="你的随机字符串" \
  -e CRYPTO_SECRET="你的加密密钥" \
  -e TZ=Asia/Shanghai \
  -v ./data:/data \
  calciumion/new-api:latest

方式四：宝塔面板

宝塔面板软件商店搜索 new-api 一键安装。

方式五：源码编译

git clone https://github.com/QuantumNous/new-api.git
cd new-api
go mod download
go build -o new-api
./new-api --port 3000
⚠️ 注意 多机集群部署时，SESSION_SECRET 必须统一设置；启用 Redis 时 CRYPTO_SECRET 必填。

7. 初始化与使用

  1. 启动容器后，浏览器打开 http://服务器IP:3000
  2. 注册第一个账号（自动获得 超级管理员 权限）
  3. 进入 渠道 页面，添加上游 API（OpenAI / Claude / Gemini 等），填入官方 Key
  4. 测试渠道是否连通（"测试"按钮）
  5. 进入 令牌 页面，创建分发 Token（即给用户用的中转 Key）
  6. 调用方式：将原 OpenAI 请求中的
    • base_url 改成 https://你的域名/v1
    • api_key 改成 New API 生成的令牌

客户端调用示例（OpenAI Python SDK）

from openai import OpenAI

client = OpenAI(
    api_key="sk-你的-new-api-令牌",
    base_url="https://你的域名/v1"
)

resp = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "你好"}]
)
print(resp.choices[0].message.content)

8. 常见问题

Q: 与 One API 有什么区别？ A: New API 基于 One API 二次开发，UI 更现代、支持更多新模型（Claude Messages、Gemini、Suno 等）、新增按量计费与缓存计费、数据库兼容。
Q: 必须用 Redis 吗？ A: 不必须。但生产环境强烈推荐，可大幅提升性能与并发能力。启用 Redis 时必须设置 CRYPTO_SECRET。
Q: 许可证限制？ A: 遵循 AGPL-3.0，二次开发对外服务必须开源衍生代码，且保留原作者署名与项目链接。
