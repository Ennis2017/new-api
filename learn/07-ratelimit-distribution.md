# 07 · 限流、分发与渠道管理

> 状态：⏳ 提纲
> 时长：约 1.5 小时

## 学习目标

- 理解 Redis 实现限流的常见算法
- 看懂多渠道负载均衡 + 故障转移机制
- 理解渠道冷却、自动禁用的策略

## 大纲

1. **限流的几种算法**
   - 固定窗口、滑动窗口、令牌桶、漏桶
   - 项目用的是哪种？
2. **`middleware/rate-limit.go` 走读**
   - 用户级、Token 级、模型级各自限流维度
3. **渠道分发：`middleware/distributor.go`**
   - 根据 model 名查 abilities 表得到候选渠道
   - 权重 / 优先级 / 分组过滤
4. **故障转移**
   - 上游失败后重试其他渠道
   - 冷却（cooldown）：失败渠道暂时不选
   - 自动禁用：连续失败自动 disable
5. **渠道健康检查**
   - 后台定时任务（看 `controller/channel-test.go` 或类似）
6. **多实例部署的协调**
   - Redis 分布式锁的用法

- [ ] 故意把一个渠道改成错误 URL，看故障转移触发
